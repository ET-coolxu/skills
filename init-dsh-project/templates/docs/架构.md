## Git

分支与提交以 [BRANCHING.md](../../BRANCHING.md) 为准：功能 `feat/*`、修复 `fix/*`，从 `dev` 切出，合回 `dev` 后删除；阶段完成再由 `dev` 合入 `main`。提交信息为 `<type>: <简体中文简述>`，`type` 取 `feat` / `fix` / `docs` / `chore` / `refactor`。不提交 `.gitignore` 已排除的文件。

## skill

本仓库的 skill 放在 `.agents/skills/`。DSH 每次只把名称和 `description` 注入会话，正文按需加载。常驻路由在 `AGENTS.md`。

| skill | 何时读取 | 约束什么 |
| --- | --- | --- |
| `.agents/skills/project/SKILL.md` | 写代码、改范围、提交前 | 范围、文档依据、工程约定 |
| `.agents/skills/iteration/SKILL.md` | 需求换版时 | 同步改 skill 和说明 |
| `.agents/skills/agent-prompts/SKILL.md` | 新需求、功能，或未要求实现时 | 先出 `需求V{n}`，确认后再整理提示词 |
